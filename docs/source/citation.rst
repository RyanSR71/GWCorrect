Citing GWCorrect
================

To cite this package, please use the following bibtex citation:

.. code:: bibtex

  @software{GWCorrect, 
    title={{GWCorrect: Bilby-dependent Python package for gravitational-waveform modification.}}, 
    author={Ryan M. Johnson and Jocelyn S. Read and Marceline S. Bonilla},
    howpublished = {\url{https://github.com/RyanSR71/GWCorrect}
  }
