# GWCorrect
Bilby-dependent Python package for gravitational-waveform modification.

## Documentation
https://waveformuncertainty.readthedocs.io/en/latest/index.html

## Installation

To use GWCorrect, install it with the following command:

```
   pip install git+https://github.com/RyanSR71/GWCorrect
```

Then, you can import the package:

```
   import GWCorrect
```
